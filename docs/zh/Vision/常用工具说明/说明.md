# 🤖 ROS2 工具使用与故障排除指南 (Humble)

## 一、 Rviz2 可视化工具

### 1. 常见问题与核心概念

- **时间同步 (Time Sync)**：
  - **现象**：若仿真时间（Simulation Time）与系统时间不匹配，Rviz 将无法正常显示数据或初始化。
  - **解决**：确保在启动节点或 Rviz 时，参数 `use_sim_time` 保持一致（通常在仿真环境下都设为 `True`）。
- **Displays 模块冲突**：
  - **原因**：订阅内容冲突（如：定义的数据类型与传入不符，或两个模块抢占同一个话题）。
  - **后果**：程序报错并可能自动关闭。
  - **解决**：先**删除**错误的显示模块，点击 **Add** 重新添加正确类型。

### 2. 交互与优化

- **图层与视角**：

  - 点击顶部菜单 `Panels` -> 勾选 `Views`。
  - 在右侧面板 `Type` 中选择 **Orbit**，即可实现顺滑的三维视角操作。

- **提升画面流畅度 (DDS 优化)**：

  - 推荐将默认 DDS 切换为 **CycloneDDS**，能显著降低延迟。

  ```
  # 安装驱动
  sudo apt install ros-humble-rmw-cyclonedds-cpp
  # 配置环境变量（建议写入 ~/.bashrc）
  export RMW_IMPLEMENTATION=rmw-cyclonedds-cpp
  ```

### 3. 手动配置 Rviz2 流程 (推荐)

为了更灵活地调试，建议取消 Launch 文件中的自动启动，改为手动配置。

#### **第一步：修改 Launch 文件**

编辑 `fishbot_navigation2/launch/navigation2.launch.py`，注释掉 Rviz 启动部分：

Python

```
# launch_ros.actions.Node(
#     package='rviz2',
#     executable='rviz2',
#     ...
# ),
```

#### **第二步：启动系统**

- **终端 1 (Gazebo):** `ros2 launch fishbot_navigation2 gazebo_sim.launch.py`
- **终端 2 (Nav2):** `ros2 launch fishbot_navigation2 navigation2.launch.py`
- **终端 3 (纯净版 Rviz):** `ros2 run rviz2 rviz2`

#### **第三步：配置显示项 (关键)**

| 模块名称           | 关键配置项                       | 说明                                       |
| ------------------ | -------------------------------- | ------------------------------------------ |
| **Global Options** | `Fixed Frame` -> `map` 或 `odom` | 必须先设置基准坐标系                       |
| **LaserScan**      | `Topic` -> `/scan_2d`            | 用于 2D 避障，建议颜色设为红色             |
| **PointCloud2**    | `Topic` -> `/scan`               | Gazebo 原始 3D 数据，建议 `Size` 设为 0.05 |
| **Map**            | `Topic` -> `/map`                | 显示静态/动态地图                          |
| **Path**           | `Topic` -> `/plan`               | 显示全局或局部规划路径                     |

导出到 Google 表格

> **💡 提示：** 配置完成后，点击 `File -> Save Config As...` 保存，下次直接加载。

## 二、 Gazebo 仿真环境

### 1. 启动卡顿 (模型下载问题)

Gazebo 启动时常因连接国外服务器下载模型而卡住。

- **解决方法**：手动克隆模型库到本地。

```
git clone https://github.com/osrf/gazebo_models.git
mkdir -p ~/.gazebo/models
cp -r ~/gazebo_models/* ~/.gazebo/models/
```

### 2. 目录结构规范

为了让 Gazebo 正确识别你的机器人模型，建议采用以下结构：

```
~/gazebo_project/
├── my_scene.world           # 场景文件
└── models/                  # 模型根目录
    └── fishbot/             # 机器人文件夹
        ├── model.config     # 模型配置文件
        ├── model.sdf        # 模型描述文件 (由 URDF 转化)
        └── meshes/          # 存放 STL/DAE 几何文件
```

- **加载环境变量**：`export GAZEBO_MODEL_PATH=$(pwd)/models:$GAZEBO_MODEL_PATH`

------

### 3. 机器人位置调整

- **实时调节**：利用 Gazebo 左上角的移动/旋转工具。
- **获取坐标**：在 `World` 标签页下的 `Models` 列表中查看 `Pose` 属性。
- **在 Launch 中固定位置**：

```
arguments=[
    '-topic', '/robot_description',
    '-entity', 'fishbot', 
    '-x', '-5.38', '-y', '1.83', '-z', '0.05', '-Y', '0.00'
]
```

## 三、 综合故障排除

### 1. 进程阻塞

如果 Gazebo 崩溃或无法关闭，强制结束后台进程：

```
killall -9 gzserver gzclient
```

### 2. Rviz2 与 Gazebo 不同步

- **检查 1**：确保两者都开启了 `use_sim_time:=true`。

- **检查 2**：检查 TF 树是否完整（`ros2 run tf2_tools view_frames`）。

- **检查 3 (话题重映射)**：如果控制无效，确认话题名是否对接成功。

  - *示例：将键盘控制话题重映射至控制器*

  ```
  ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args -r /cmd_vel:=/fishbot_diff_drive_controller/cmd_vel_unstamped
  ```
